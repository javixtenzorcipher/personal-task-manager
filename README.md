Personal Task Manager

A simple task management web application built with Laravel.

Features

- Add a new task
- View all tasks
- Edit tasks
- Update tasks
- Delete tasks
- Set task status to Pending or Completed
- Set a due date
- Form validation
- Delete confirmation

Task Fields

- Task Name
- Description
- Status
- Due Date

Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- JavaScript

Database

The application uses a `tasks` table containing:

- `id`
- `task_name`
- `description`
- `status`
- `due_date`

 Project Structure

The application follows the Laravel structure:

Routes → Controller → Model → Database → Blade Views**

Purpose

This project was created as a Laravel CRUD application to demonstrate basic task management and the connection between routes, controllers, models, database migrations, and Blade views.
